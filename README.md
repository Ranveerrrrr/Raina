# 🛡️ Raina – Cybersecurity Awareness Project

**Raina** is a student-led initiative designed to promote **cybersecurity awareness** and encourage safe, responsible online behavior.
The project demonstrates common cybersecurity tools and techniques in an **educational, non-exploitative** manner.

It’s built as a **web-based toolkit** using **HTML, Tailwind CSS, and JavaScript**, focusing on simplicity, interactivity, and transparency — all while ensuring **no personal data is collected or stored**.

---

## 🎯 Purpose

The goal of **Raina** is not to provide a hacking platform, but to **educate**.
It helps students and learners understand how cybersecurity tools work under the hood — fostering awareness of online safety, privacy risks, and ethical hacking principles.

---

## 🔑 Features

Each tool in Raina is built to simulate real cybersecurity functions **without exposing or storing any user data**.

Some examples include:

* 📨 **Email Breach Check** — Demonstrates how breach-checking tools work conceptually (no data saved).
* 🧩 **Hash Generator** — Converts input into common hash formats (MD5, SHA-1, SHA-256) locally in the browser.
* 🌐 **IP Information Lookup** — Shows how IP data can be analyzed using public APIs.
* 🔗 **Link Analyzer** — Teaches users how malicious links can be identified.
* 🔐 **Phishing Awareness** — Displays examples of phishing attempts for learning purposes.
* 💾 **File Scanner (conceptual)** — Explains how online file scanning tools assess file integrity and reputation.

All processing happens **locally in your browser** — Raina never sends, logs, or stores input data.

---

## 🧠 Technology Stack

* **Frontend:** HTML, Tailwind CSS, JavaScript
* **Hosting:** Firebase Hosting
* **No backend or database** — all tools run client-side
* **Optional APIs:** Public APIs (for demonstration only; no API keys are stored in this repo)

---

## 🔒 Privacy & Transparency

Raina was created to be **completely transparent**.
Anyone can view the source code to verify that **no data collection, tracking, or storage** occurs.

This project aims to help learners trust and understand cybersecurity tools by showing how they work — **openly and safely**.
